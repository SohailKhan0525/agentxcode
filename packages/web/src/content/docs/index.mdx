# AgentX Code

AgentX Code is an open-source AI coding agent built around your repository, your terminal, and your workflow.

It reads the project first, helps you make a plan, executes focused changes, and leaves verification in your hands.

[Install AgentX](/docs/cli) · [Explore the agents](/docs/agents) · [View source](https://github.com/SohailKhan0525/agentxcode)

---

## Quick start

Install the CLI globally:

```bash
npm i -g @agent-qofeno/agentx-cli@latest
```

Then open a repository and start AgentX:

```bash
cd your-project
agentx
```

### The workflow

1. **Read** — AgentX inspects the repository and its project rules.
2. **Plan** — use the read-only `plan` agent to explore and design the change.
3. **Build** — switch to `build` when you're ready to edit.
4. **Verify** — run the project's checks and review the result.

:::tip[Plan before you build]
Press `Tab` to switch between the built-in agents. The `plan` agent is designed for analysis and code exploration without editing files.
:::
